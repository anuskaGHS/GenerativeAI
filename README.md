# Generative AI: Weekly Assignments

> **Academic notice:** This repository is created **only for university submission purposes**. It holds my weekly assignments for the Generative AI course in the BCA (AI & ML) programme at Alliance University, Bangalore (Semester V). It is not a standalone project. Please do not copy this work for your own submissions.

## What is in this repository

Eleven Jupyter notebooks, one per weekly assignment. Each notebook states its objective at the top and then works through the steps with code and short explanations.

| # | Assignment | Main topic |
|---|---|---|
| 1 | Understanding Generative and Discriminative Models Using MNIST | Generative vs discriminative models (digits 0 and 1) |
| 2 | Exploring Text Generation Using GPT-2 | How generation parameters change the output |
| 3 | Identifying Bias in a Pretrained Generative AI Model | Bias in GPT-2 outputs for neutral prompts |
| 4 | Training a DCGAN on the Fashion-MNIST Dataset | Generator and discriminator training |
| 5 | Exploring the Latent Space of a Pretrained StyleGAN2 Model | Smooth changes in generated images |
| 6 | Applying AI-Based Style Transfer to an Image | CycleGAN vs VGG-based neural style transfer |
| 7 | Creating and Fixing Mode Collapse in a GAN | Why GANs fail and how to improve training |
| 8 | Building a Variational Autoencoder and Visualising Its Latent Space | VAE on MNIST |
| 9 | Using a Variational Autoencoder for Compression and Denoising | Practical uses of a VAE |
| 10 | Comparing GAN and VAE Using Your Own Experimental Results | Comparing the results of Assignments 4 and 8 |
| 11 | Fine-Tuning GPT-2 on a Custom Text Style | Fine-tuning a pretrained language model |

## Tools and libraries

Python, PyTorch, torchvision, TensorFlow, scikit-learn, Hugging Face Transformers (GPT-2), NumPy, Matplotlib, Jupyter Notebook.

## How to open the notebooks

1. Clone the repository:
   ```bash
   git clone https://github.com/anuskaGHS/GenerativeAI.git
   ```
2. Open any `AssignmentN_GenAI.ipynb` file in Jupyter Notebook or Google Colab.
3. Run the cells from top to bottom. Some assignments download datasets or pretrained models, so an internet connection is needed.
